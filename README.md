# JANスキャナー 仕入管理システム

弥生販売連携 / Flutter ネイティブアプリ / Python RPA 構成による仕入業務自動化システム。

## システム概要

JANコード（バーコード）をスマートフォンまたはPCで読み取り、同一ネットワーク内のPCに転送して仕入伝票の作成・弥生販売への自動登録を行う。

## 構成コンポーネント

| コンポーネント | 技術 | 役割 |
|---|---|---|
| モバイルアプリ | Flutter (Dart) | JANスキャン・数量入力・伝票確定 |
| PCサーバー | Python 3.11 + FastAPI | 商品照合・伝票生成・RPA制御 |
| 商品マスタDB | SQLite | 弥生販売CSVのローカルキャッシュ |
| RPA自動化 | pywinauto | 弥生販売 26 のUI自動操作 |
| JAN検索（一次） | 楽天ウェブサービスAPI | 不明JANの商品名自動取得 |
| JAN検索（補助） | Open Food Facts API | 食品の補完検索 |
| 在庫・販売管理 | 弥生販売 26（既存） | 仕入伝票確定・在庫管理の唯一の正者 |

## ディレクトリ構成

```
jan-scanner/
├── server/          # Python FastAPI サーバー
├── app/             # Flutter モバイルアプリ
├── rpa/             # Python RPA スクリプト（pywinauto）
└── docs/            # 設計書・ドキュメント
```

## 主要設計決定

- **在庫の正者**: 弥生販売のみ（このシステムは仕入伝票生成に特化）
- **RPA対象バージョン**: 弥生販売 26 固定
- **認証**: PINコード（4〜6桁）を全リクエストに付与
- **RPA排他制御**: asyncio.Queue によるキュー方式
- **RPA失敗時**: ログ保存 + PC画面アラート + 手動再実行
- **セッションタイムアウト**: 30分で自動タイムアウト、未確定データは下書き保存
- **ネットワーク**: PCのIPを固定化、アプリ初回設定時に手動入力
